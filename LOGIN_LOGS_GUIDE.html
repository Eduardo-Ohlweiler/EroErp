Login Logs Feature - Implementation Guide

Complete reference for adding the "Login Logs" submenu under Administration (SUPERADMIN only) with a list page featuring date range filters.

1. Administrative Menu Structure

Menu Configuration File

/home/eduardo/Documentos/EroErp/ero/src/config/menu.ts

Key Points:

  • Menu is defined as an array of MenuItem objects
  • SUPERADMIN-only items use roles: ["SUPERADMIN"]
  • Submenus (like "Logs") are created with children: MenuItem[]
  • Nested items can have further children (up to 3 levels deep)

Key Role Gating Logic (lines 52-64):

// temAcesso: checks if user has at least one of the required roles function temAcesso(item: MenuItem): boolean { if (!item.roles || item.roles.length === 0) return true return item.roles.some((role) => hasRole(role)) } // filtrarMenu: recursively filters menu based on user roles function filtrarMenu(items: MenuItem[]): MenuItem[] { return items .filter(temAcesso) .map((item) => ({ ...item, children: item.children ? filtrarMenu(item.children) : undefined })) }
